# PrintCalc 3D — калькулятор стоимости печати (Bambu Lab P2S Combo + AMS 2 Pro)

Windows Forms, C#, .NET 8. Версия 1.2.0.

## Сборка

### Вариант 1. Visual Studio 2022 (17.8+, нагрузка «Разработка классических приложений .NET»)
1. Откройте `PrintCalc3D.csproj`.
2. Конфигурация **Release**, затем **F5** (или Ctrl+F5).
3. Готовый exe: `bin\Release\net8.0-windows\PrintCalc3D.exe`.

### Вариант 2. Двойной щелчок по `build-exe.bat`
Соберёт один небольшой файл `dist\PrintCalc3D.exe` (нужен .NET 8 Desktop Runtime на ПК запуска; сеть не нужна).
`build-exe-selfcontained.bat` — автономный файл без установки .NET (нужен доступ к nuget.org).

### Вариант 3. Без своего компьютера — сборка на GitHub
Загрузите папку проекта в свой репозиторий GitHub (файл `.github/workflows/build.yml` уже есть) →
вкладка **Actions** → **build-exe** → **Run workflow** → скачайте `PrintCalc3D-win-x64` внизу страницы запуска.

### Если NuGet пишет «127.0.0.1:10809 — подключение отвергнуто»
В Windows включён прокси, а программа, которая его поднимает (VPN/прокси-клиент), не запущена. Запустите её
или отключите прокси: Параметры → Сеть и Интернет → Прокси → «Использовать прокси-сервер» → Выкл.
Проект по умолчанию собирается без NuGet.

## Что нового в 1.2
- Кнопка **«Рассчитать»** под временем и массой (работает и клавиша **Enter**). Результат не мелькает при вводе;
  подсказка под кнопкой показывает, актуален ли расчёт.
- Справа рядом с ценой для клиента крупно показана **себестоимость**; в разделе «Заказ» добавлена наценка.
- Шапка: текст **сам уменьшает шрифт** под ширину окна (`FitText.cs`), больше не срезается.
- Без мерцания при сворачивании/разворачивании: окно рисуется целиком в буфере (`WS_EX_COMPOSITED`),
  панели и таблицы с двойной буферизацией, скрытый браузер для цен не отбирает фокус.
- Быстрее и легче: ставки за час считаются один раз и кэшируются; цены магазинов грузятся и разбираются
  параллельно в пуле потоков (до 8), а не в потоке интерфейса; таймеры в простое выключены.

## Формулы
- Часов работы принтера в месяц = рабочих дней (21,3) × часов печати в сутки
- Электричество, ₽/ч = мощность (кВт) × тариф
- ЗП, ₽/ч = ЗП в месяц ÷ часов в месяц (выключается галочкой)
- Амортизация, ₽/ч = цена принтера ÷ срок окупаемости (12 мес.) ÷ часов в месяц
- Сопутствующие, ₽/ч = 10 % цены принтера ÷ 6 мес. ÷ часов в месяц
- Пластик = масса из слайсера × 1,10 ÷ 1000 × цена за кг
- Себестоимость = время × (сумма ставок за час) + пластик
- Цена для клиента = себестоимость × (1 + наценка)
- Окупаемость: чистая прибыль с заказа (без амортизации) → сколько заказов в месяц
  нужно, чтобы принтер окупился за 12 месяцев, и срок окупаемости при вашем потоке заказов.

## Автообновление цены принтера
В Настройках в поле «Ссылки на страницы товара» вставьте ссылки на страницу P2S Combo
в российских магазинах (по одной в строке) и нажмите «Проверить и обновить цену».
Для каждой ссылки программа делает так:

1. Загружает страницу как обычный браузер и ищет цену в разметке товара
   (meta, JSON-LD, itemprop, data-price), а если не нашла — по тексту вида «109 990 ₽».
2. Если сайт заблокировал запрос или цена подставляется скриптом, страница открывается
   в скрытом браузере, и цена читается уже после отрисовки.

Если системный прокси Windows указан, но не запущен, запрос автоматически повторяется напрямую.
Итоговая цена — медиана по всем ссылкам. Под кнопкой проверки выводится журнал по каждой ссылке
(например, «HTTP 403» или «цена не найдена»). Автообновление повторяется при запуске и каждые 6 часов;
без интернета остаётся последнее значение. Цену можно задать вручную (автообновление тогда отключается).

### Скрытый браузер: два режима
- **По умолчанию** — встроенный в Windows компонент WebBrowser. Сборка идёт без интернета и без NuGet.
- **Edge WebView2** (точнее на современных сайтах) — в `PrintCalc3D.csproj` поменяйте
  `<UseWebView2>false</UseWebView2>` на `true` (нужен nuget.org и WebView2 Runtime — в Windows 11 он уже есть).

## Производительность — как это устроено (честно)
- **Расчёт цены** — несколько умножений (доли микросекунды). Раскидывать его по ядрам бессмысленно: потоки
  стоили бы в тысячи раз дороже самого расчёта и дали бы только задержки. Вместо этого формулы разделены на
  «зависящие от настроек» (считаются один раз и кэшируются, сбрасываются при сохранении настроек) и
  «зависящие от заказа» (3–4 умножения).
- **Потоки (4 ядра / 8 потоков)** используются там, где есть что распараллеливать: загрузка и разбор страниц
  магазинов идут одновременно (до `PerfConfig.MaxParallel` = 8), вне потока интерфейса — окно не подвисает.
  Пул потоков при старте прогрет до 8.
- **60 кадров в секунду**: обновления интерфейса объединяются так, что за 16 мс выполняется не больше одного
  (`FrameCoalescer.cs`). Постоянного таймера «на 60 Гц» нет — в простое программа не потребляет процессор.
- **Мерцание**: `WS_EX_COMPOSITED` на главном окне. Если на каком-то ПК появятся артефакты отрисовки —
  в `PerfConfig.cs` поставьте `UseCompositedWindow = false`.

## Перенос на другой компьютер
Настройки и база пластика лежат в `%AppData%\PrintCalc3D\settings.json` — скопируйте файл на другой ПК,
чтобы сохранить тариф, ЗП, ссылки на магазины и цены пластика. Исходники — вся эта папка.
